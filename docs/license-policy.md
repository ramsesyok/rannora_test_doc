依存ライブラリや第三者から転用した部分には元の条件が残ります。本文・著作権・NOTICE と固定バージョンのソース取得先を [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) に収録します。プロジェクトの MIT 表示で依存ライブラリを一括して再許諾することはありません。

```sh
go run scripts/licenses.go
go run scripts/licenses.go -check
```

生成対象は CGO 無効の Linux / macOS / Windows、amd64 / arm64 の通常ビルドの依存です。Go ランタイムの表示も含みます。CI は生成物の鮮度を確認し、GoReleaser はリリース時に再生成して LICENSE とともにアーカイブへ同梱します。

生成ツールは法的な互換性やソースの由来を判定しません。依存の追加・更新時には、新しいライセンス、ソースコメント内だけの条件、生成・転用コードも確認してください。`replace` は実際のソース取得先と変更内容の個別確認が必要なため、生成を止めます。過去の配布物にはこの変更が遡って反映されないため、過去版を配布する場合も対応する表示を用意してください。

GoReleaser の go-winres はビルド時に外部で実行するツールです。生成した Windows リソースには外部のアイコンや素材を追加していません。将来追加する場合は素材の許諾を確認してください。Quarto / Pandoc / Typst / ddq は外部の文書生成ツールとしてそれぞれの条件に従います。

出力文書の権利は入力 runbook、データ、利用するテンプレート等にも依存します。runnora-docgen を実行したことによって入力由来の権利が MIT に変わることはありません。
